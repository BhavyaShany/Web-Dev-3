*Assignment Overview*

The *Smart Utility Toolkit* is a hands-on lab assignment designed to help students understand the  fundamentals of backend development using Node.js core modules. 
In this lab, students will build multiple mini utilities using built-in Node.js modules such as process,  http, fs, and crypto, while also learning how to create and reuse custom modules in real-world  scenarios. 
The assignment focuses on command-line interaction, modular programming, server creation, file  handling, and randomness generation—without using any external packages or frameworks. 
This assignment simulates practical backend development tasks and helps students understand how  Node.js works internally through hands-on experimentation.

*Problem Statement*

Build a simple *CLI-based calculator* using *process.argv* to perform operations like addition and  subtraction, create a custom module (e.g., isEven or logger module) and reuse it in another file,  develop a basic HTTP server using the http module that returns different responses on different routes,  implement a file manager using fs module to create, read, update, and delete files, and create a  random dice generator using crypto module to simulate real-world randomness.
