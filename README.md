# Web Development III

This repository contains my coursework, assignments, practicals, and projects completed as part of the **Web Development III** course during my **3rd semester**.

Web Development III primarily focuses on **backend development**, where I explore how server-side applications work and how backend systems handle requests, data, files, APIs, and application logic.

Throughout the semester, new assignments, practicals, and projects will be added to this repository as I continue learning and implementing different backend development concepts.

## Topics Covered

Some of the concepts explored in this course include:

* Node.js fundamentals
* Backend development
* Node.js core modules
* ES Modules
* HTTP servers and routing
* Express.js
* REST APIs
* Middleware
* File handling
* Command-line arguments
* Modular programming
* Database integration
* Authentication and authorization
